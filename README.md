# AUD722 – My Creature
δημιουργία ενός ηχητικού Creature στο SuperCollider με τη χρήση του EvoLab.

Ως βασικός ήχος χρησιμοποιήθηκε μια ηχογράφηση γαβγίσματος σκύλου, η οποία
μεταβάλλεται ανάλογα με την κατάσταση στην οποία βρίσκεται το Creature.

dawn
day
dusk
night
danger

Σε κάθε κατάσταση ο βασικός ήχος επεξεργάζεται με διαφορετικό τρόπο, ώστε να αλλάζει η ηχητική συμπεριφορά του Creature.

Εξεταστική Σεπτεμβρίου 2026.
